# UI Design Skill

Before implementing UI, read the repository `DESIGN-SYSTEM.md` and relevant sections of `project-spec.md`.

## Required behavior

- Preserve the dark tactile visual language.
- Use the approved Spectrum Material intentionally.
- Treat glass as a material, not a default card style.
- Keep corners soft and consistent.
- Use system-first typography.
- Prefer simple, readable iconography.
- Keep the mobile layout primary.
- Respect iPhone 8 performance constraints.
- Respect reduced motion.

## Review checklist

Before finishing UI work, verify:

- hierarchy is clear
- primary action is obvious
- spacing is consistent
- no accidental extra gradients/glows
- no unnecessary glass
- no heavy shadows
- no generic SaaS/dashboard styling
- no random icons
- interactions remain usable without gestures
- layout works on narrow iPhone 8 width
